## Files in this bundle

- `kanji/*.svg` — 112 unmodified SVG files for hiragana/katakana (`kana.json`) and N4 kanji (`kanji.json`) referenced by `strokeData.kanjiVgId`
- `manifest.json` — index of bundled codepoints (generated by `scripts/build-kanjivg-bundle.mjs`)
- `COPYING` — KanjiVG license text from the upstream repository

## Luna usage

SVG files are served as static assets and rendered in the browser. Luna’s React/canvas code does **not** modify these SVG files. Runtime parsing is used only for stroke-order validation and animation overlays.

To regenerate the bundle from an official KanjiVG release (not run during production build):

```bash
npm run kanjivg:bundle
# or from a local KanjiVG checkout:
node scripts/build-kanjivg-bundle.mjs --source /path/to/kanjivg/kanji
```
