# Piani di implementazione

Salva qui i piani creati in **Plan mode** (`Shift+Tab` nell'agente).

## Come usare

1. In Plan mode, chiedi un piano per la feature (es. "Aggiungi login Google").
2. Rivedi e modifica il piano nell'editor.
3. Clicca **Salva nel workspace** → file in questa cartella.
4. In una **nuova sessione** Agent, riferisciti al piano: `@.cursor/plans/nome-piano.md`

## Per feature grandi

Se il piano è complesso, valuta di creare anche `SPEC.md` nella root con requisiti e criteri di accettazione.

## Naming

`YYYY-MM-DD-feature-breve.md` — es. `2026-06-15-teacher-notifications.md`
